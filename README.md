# ASALA store demos

Design demos for ASALA, handmade earrings from Nablus inspired by Islamic architecture and Palestinian tatreez.
Open `index.html` (the GitHub Pages home) to see all 29 demos with a short note on each.

- All prices, delivery fees, delivery times and policies are placeholders.
- No order is ever sent: checkout is a demo.
- Brand images come from the ASALA brand book. Demos marked "earlier style directions" use free Unsplash photos (see `img/SOURCES.txt`).
